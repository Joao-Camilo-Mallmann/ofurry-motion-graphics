# Mapa conceito -> icone (Lucide)

Todos os nomes existem no `lucide-react` instalado. "Animado" = existe tambem no Lucide Animated
(`src/lucide-animated/icons`) e o `IconBeat` usa essa versao automaticamente; passe `animated: false` para
forcar o estatico. Busca completa: https://lucide.dev/icons e https://lucide-animated.com.
