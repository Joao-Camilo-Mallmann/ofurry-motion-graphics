# Lucide Animated — atribuição

Os arquivos em `icons/` são gerados por `scripts/sync-lucide-animated.ts` a partir do
registro público de https://lucide-animated.com (repositório `pqoqubbw/icons`),
distribuído sob a licença MIT. Os desenhos base vêm do Lucide (https://lucide.dev, ISC).

A única modificação feita é a troca de `motion/react` pelo `motion-shim.tsx` deste projeto,
para que a animação seja determinística por frame dentro do Remotion.

Mantenha esta nota e os avisos de licença ao redistribuir o código.
